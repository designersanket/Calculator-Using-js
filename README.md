# Description:
A modern, responsive, and visually appealing calculator built using HTML, CSS, and JavaScript. Features a neumorphic design with smooth button animations and a fully functional display for arithmetic operations. Perfect for learning front-end development and UI styling.

# Features:

Clean and modern neumorphic design.

Fully responsive for desktop and mobile devices.

Supports basic arithmetic: +, -, *, /, %.

Interactive buttons with hover and press effects.

Clear (C) button spans full width for easy resetting.

Easy to customize colors, fonts, and layout.

Technologies Used:

HTML5

CSS3 (including flex/grid and gradients)

JavaScript (DOM manipulation and event handling)

Live Demo: calculator-using-js-blond.vercel.app
